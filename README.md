# AI Coding Assistant

Local AI Coding Assistant built using:

- Vue.js
- FastAPI
- Ollama
- DeepSeek-Coder
- LangChain
- ChromaDB

## Features

- AI chat interface
- Local LLM integration
- FastAPI backend
- Vue frontend
- File upload system
- RAG pipeline (in progress)

## Tech Stack

### Frontend
- Vue.js
- Axios

### Backend
- FastAPI
- LangChain
- Ollama

### AI / RAG
- DeepSeek-Coder
- nomic-embed-text
- ChromaDB
